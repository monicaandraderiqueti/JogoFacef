# Strawberry Game
# Descrição
Este jogo o qual está presente no repositório teve desenvolvimento no "Construct 3" composto de gráficos coloridos e estilo em pixel art, com integração ao banco de dados "Firebase". O jogo tem como contexto atacar e eliminar os inimigos morangos podres, utilizando de morangos explosivos da personagem player, para jogá-los utiliza-se o botão esquerdo do mouse. Durante o jogo surgirão inimigos a cada segundo, tome cuidado e sobreviva com a maior pontuação possível.

# Como jogar
O jogo tem a mobilidade de 8 direções, utilizando as teclas de setas do teclado, do botão esquerdo do mouse para atacar os morangos, a tecla "espaço" para reiniciar o jogo e usando também o ângulo em que o mouse se encontra como direção do personagem.
